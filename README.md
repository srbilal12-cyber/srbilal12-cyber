## 🚀 Featured Project

### [HemoScan](https://hemo-scan--srbilal12.replit.app/)

A learning and research prototype exploring camera-based visual signals for an estimated hemoglobin-related result.

- Built as a web application using React.
- Includes eye and nail scan modes and a scan-history interface.
- **Important:** HemoScan is a research prototype, not a medical device. Its results are not a substitute for laboratory testing or professional medical advice.
